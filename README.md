# Wireshark SOC Traffic Analysis

## Project Overview

This repository documents my hands-on experience completing a Wireshark SOC (Security Operations Center) network traffic analysis module.

The project focused on analysing captured network traffic, identifying suspicious activities, investigating potential attacks, and understanding how network protocols can reveal important security information.

## Objectives

The main objectives of this practical exercise were to develop skills in:

- Identifying attacker IP addresses through packet analysis.
- Detecting clear-text passwords and exposed credentials.
- Investigating brute-force attack attempts.
- Analysing VoIP traffic and identifying voice communications.
- Discovering hidden data within network packets.
- Following TCP streams to reconstruct network conversations.
- Understanding suspicious network communication patterns.

## Practical Exercises

| Exercise | Description |
|---|---|
| Attacker Identification | Analysing packet sources to identify suspicious IP addresses. |
| Clear-Text Passwords | Identifying credentials transmitted without encryption. |
| Brute-Force Detection | Investigating repeated authentication attempts. |
| VoIP Analysis | Examining voice communication traffic. |
| Hidden Data | Investigating packets for concealed information. |
| Follow TCP Stream | Reconstructing conversations between communicating hosts. |

## Challenges Faced

During the practical exercises, some of the challenges included:

- Understanding different packet protocols and their functions.
- Identifying the correct source and destination IP addresses.
- Distinguishing normal traffic from suspicious activities.
- Applying the correct Wireshark display filters.
- Analysing large volumes of captured packets.
- Interpreting TCP streams and identifying relevant information.

These challenges helped improve my understanding of network traffic investigation and practical security monitoring.

## Learning Outcome

This project strengthened my understanding of how SOC analysts use network traffic analysis to investigate suspicious activities, detect potential threats, and gather evidence during security investigations.

## Disclaimer

This project was conducted for educational and cybersecurity training purposes using authorised lab traffic and practice captures. Any investigation involving credentials or sensitive information should only be performed with proper authorisation.
